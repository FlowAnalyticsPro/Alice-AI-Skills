# Template de sortie — Planning Capacity

```
## Capacity Planning — [Projet] — [Prochain sprint / Période]

**Recommandation : [N items / X points]**
Niveau de confiance : [🟢 Élevé / 🟡 Modéré / 🔴 Saturé]

### Calcul
- Capacité brute : X [points/items]
- Déductions : -X (en cours) / -X (bloqués)
- Capacité nette : X
- Buffer appliqué : -X% ([raison])
- **→ Recommandation : X [points/items]**

### Signaux à surveiller
[Goulot ou risque identifié, si applicable]

### Action recommandée
→ [1 action concrète]
```

## Règles de rédaction

- Toujours exprimer la recommandation en nombre entier (arrondi inférieur)
- Si Scrum : exprimer en points ET en nombre d'items estimés
- Rappeler la loi de Little si WIP proche de la limite
